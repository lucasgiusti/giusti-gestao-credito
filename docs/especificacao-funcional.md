## Documento de Especificação Funcional

**Versão:** 1.0  
**Data:** 18/07/2025  
**Preparado por:** Product Owner

## Sumário Executivo

Este documento apresenta a especificação funcional do Sistema Giusti Gestão de Créditos, uma solução desenvolvida para gerenciar o processo completo de aquisição e acompanhamento de créditos provenientes de processos judiciais, trabalhistas, precatórios e NPL (Non-Performing Loans). O sistema abrange desde a identificação inicial de oportunidades até o monitoramento contínuo dos créditos adquiridos, proporcionando uma plataforma integrada para maximizar o retorno dos investimentos com governança e controle.

## Visão Geral do Sistema

O Sistema Giusti Gestão de Créditos é uma plataforma que permite o gerenciamento completo do ciclo de vida de créditos adquiridos, desde a identificação de oportunidades até o monitoramento e cobrança dos créditos comprados. O sistema é projetado para suportar o fluxo de trabalho específico de empresas que negociam a compra de direitos creditórios oriundos de processos judiciais.

### Tecnologias Principais

O sistema será desenvolvido utilizando as seguintes tecnologias:

- **Frontend**: React com Next.js, proporcionando uma interface moderna e responsiva
- **Backend**: API RESTful desenvolvida com NestJS
- **Banco de Dados**: PostgreSQL via Supabase
